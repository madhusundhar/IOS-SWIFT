## 📑 Unit 1: Control Flow & Decision-Making

### Level 1: Simple
- **Task 1.1** ([`Task1_1_PositiveNegativeZero.swift`](Unit1_ControlFlow/Level1_Simple/Task1_1_PositiveNegativeZero.swift)): Integer positive, negative, or zero check with `if / else if / else`.
- **Task 1.2** ([`Task1_2_EvenOdd.swift`](Unit1_ControlFlow/Level1_Simple/Task1_2_EvenOdd.swift)): Even or odd number check using `% 2`.
- **Task 1.3** ([`Task1_3_StudentGrade.swift`](Unit1_ControlFlow/Level1_Simple/Task1_3_StudentGrade.swift)): Student grade calculator (A, B, C, D, F) using `if / else if`.
- **Task 1.4** ([`Task1_4_SwitchDayName.swift`](Unit1_ControlFlow/Level1_Simple/Task1_4_SwitchDayName.swift)): Day name for numbers 1–7 using `switch`.
- **Task 1.5** ([`Task1_5_ForInLoop.swift`](Unit1_ControlFlow/Level1_Simple/Task1_5_ForInLoop.swift)): Loop 1 to 10 using `for-in` and `1...10`.
- **Task 1.6** ([`Task1_6_MultiplicationTable.swift`](Unit1_ControlFlow/Level1_Simple/Task1_6_MultiplicationTable.swift)): Multiplication table up to 10.
- **Task 1.7** ([`Task1_7_TernaryOperator.swift`](Unit1_ControlFlow/Level1_Simple/Task1_7_TernaryOperator.swift)): Larger of two numbers using `(a > b) ? a : b`.
- **Task 1.8** ([`Task1_8_WhileCountdown.swift`](Unit1_ControlFlow/Level1_Simple/Task1_8_WhileCountdown.swift)): Countdown from 10 down to 1 using `while`.

### Level 2: Intermediate
- **Task 1.9** ([`Task1_9_LargestOfThree.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_9_LargestOfThree.swift)): Largest of three numbers using nested `if`.
- **Task 1.10** ([`Task1_10_LeapYear.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_10_LeapYear.swift)): Leap year validation (divisible by 4, except centuries not divisible by 400).
- **Task 1.11** ([`Task1_11_SumOfDigits.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_11_SumOfDigits.swift)): Sum of digits using `while` loop, `% 10`, and `/ 10`.
- **Task 1.12** ([`Task1_12_Fibonacci.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_12_Fibonacci.swift)): Fibonacci sequence up to `n` terms.
- **Task 1.13** ([`Task1_13_PrimeNumbers.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_13_PrimeNumbers.swift)): Prime number checker and primes between 1 and 50.
- **Task 1.14** ([`Task1_14_Calculator.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_14_Calculator.swift)): Simple calculator with `switch` and division by zero protection.
- **Task 1.15** ([`Task1_15_FizzBuzz.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_15_FizzBuzz.swift)): FizzBuzz from 1 to 30.
- **Task 1.16** ([`Task1_16_StarTriangle.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_16_StarTriangle.swift)): Nested loops star triangle pattern with `continue` to skip even rows.
- **Task 1.17** ([`Task1_17_PalindromeArmstrong.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_17_PalindromeArmstrong.swift)): Palindrome and Armstrong number verification.
- **Task 1.18** ([`Task1_18_BMICategorisation.swift`](Unit1_ControlFlow/Level2_Intermediate/Task1_18_BMICategorisation.swift)): BMI categorisation using `switch` with ranges and `where` clauses.

### Additional Tasks (Operators and Expressions)
- **Task 1** ([`Task1_RestaurantBill.swift`](Unit1_ControlFlow/Additional_Tasks/Task1_RestaurantBill.swift)): Guided activity restaurant bill calculator with subtotal, coupon discount, GST, split, and rupee breakdown.
- **Task 2** ([`Task2_LeapYearRangeChecks.swift`](Unit1_ControlFlow/Additional_Tasks/Task2_LeapYearRangeChecks.swift)): Pure Boolean expressions without `if` statements (leap years, `1...100`, even & not multiple of 10, nil-coalescing).
- **Task 3** ([`Task3_PredictOutput.swift`](Unit1_ControlFlow/Additional_Tasks/Task3_PredictOutput.swift)): Precedence, integer division, modulo signs, bitwise shifts, and overflow operators (`&+`).

## 📑 Unit 3: Enumerations, Structures and Classes

### Level 1: Simple
- **Task 3.1** ([`Task3_1_DirectionEnum.swift`](Unit3_EnumStructClass/Level1_Simple/Task3_1_DirectionEnum.swift)): Enum `Direction` with `switch`.
- **Task 3.2** ([`Task3_2_WeekdayEnum.swift`](Unit3_EnumStructClass/Level1_Simple/Task3_2_WeekdayEnum.swift)): Enum `Weekday: Int` with raw values 1–7 and raw value initialization.
- **Task 3.3** ([`Task3_3_StudentStruct.swift`](Unit3_EnumStructClass/Level1_Simple/Task3_3_StudentStruct.swift)): Struct `Student` with name, rollNumber, and marks.
- **Task 3.4** ([`Task3_4_StudentIsPassed.swift`](Unit3_EnumStructClass/Level1_Simple/Task3_4_StudentIsPassed.swift)): Method `isPassed()` returning true if marks >= 40.
- **Task 3.5** ([`Task3_5_RectangleArea.swift`](Unit3_EnumStructClass/Level1_Simple/Task3_5_RectangleArea.swift)): Struct `Rectangle` with computed property `area`.
- **Task 3.6** ([`Task3_6_PersonClass.swift`](Unit3_EnumStructClass/Level1_Simple/Task3_6_PersonClass.swift)): Class `Person` with initializer and `introduce()` method.
- **Task 3.7** ([`Task3_7_CarClass.swift`](Unit3_EnumStructClass/Level1_Simple/Task3_7_CarClass.swift)): Class `Car` with `accelerate()` and `brake()` methods.

### Level 2: Intermediate
- **Task 3.8** ([`Task3_8_PlanetEnum.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_8_PlanetEnum.swift)): `Planet: CaseIterable` with computed `orderFromSun`.
- **Task 3.9** ([`Task3_9_PaymentMethod.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_9_PaymentMethod.swift)): Enum `PaymentMethod` with associated values (`.cash`, `.card(number:)`, `.upi(id:)`).
- **Task 3.10** ([`Task3_10_BankAccount.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_10_BankAccount.swift)): Struct `BankAccount` with mutating `deposit()` and `withdraw()` with overdraft protection.
- **Task 3.11** ([`Task3_11_ValueVsReference.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_11_ValueVsReference.swift)): Demonstration and technical explanation of Value (Struct) vs Reference (Class) semantics.
- **Task 3.12** ([`Task3_12_VehicleInheritance.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_12_VehicleInheritance.swift)): Inheritance with `Vehicle`, `Car`, and `Bike` overriding `description()`.
- **Task 3.13** ([`Task3_13_PropertyObserver.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_13_PropertyObserver.swift)): Property observer `didSet` on `Employee.salary`.
- **Task 3.14** ([`Task3_14_FailableInitializer.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_14_FailableInitializer.swift)): Failable initializer `init?(name:marks:)` returning `nil` if marks outside 0–100.
- **Task 3.15** ([`Task3_15_LibraryManagement.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_15_LibraryManagement.swift)): `Book` and `Library` classes with add, remove, search, and list.
- **Task 3.16** ([`Task3_16_StaticMembers.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_16_StaticMembers.swift)): Static methods (`MathHelper.square`) and static property tracking instance count (`Counter`).
- **Task 3.17** ([`Task3_17_StudentManagementSystem.swift`](Unit3_EnumStructClass/Level2_Intermediate/Task3_17_StudentManagementSystem.swift)): Mini project with `Student`, `Grade`, and `School` producing sorted reports.

### Additional Tasks (Topic 5: Enums, Structs, and Classes)
- **Task 1** ([`Task1_LibraryItemModel.swift`](Unit3_EnumStructClass/Additional_Tasks/Task1_LibraryItemModel.swift)): Guided activity with `BookStatus` enum, `Book` struct, and `Member` class demonstrating copying vs reference sharing.
- **Task 2** ([`Task2_ShapesAndAreas.swift`](Unit3_EnumStructClass/Additional_Tasks/Task2_ShapesAndAreas.swift)): `Shape` enum with associated values & areas, and `Rectangle` struct with mutating `scale(by:)`.
- **Task 3** ([`Task3_CompileErrorAndIdentity.swift`](Unit3_EnumStructClass/Additional_Tasks/Task3_CompileErrorAndIdentity.swift)): Challenge task diagnosing `let` struct mutation compile error, fixing it, explaining reference types, and using `===` identity operator.
